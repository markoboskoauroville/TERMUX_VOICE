- 15.11.2026: Termux:Boot must match Termux's signer (Nothing: F-Droid build, not the GitHub debug one). Boot cannot be tested by adb broadcast; reboot the phone (Pixel proved it). A PRoot-hosted daemon dies with PRoot and an in-place /update of it can leave it dead (Nothing after update: no answer): update such a daemon only when a native shell can restart it. Never test locally on Mac with the first curl right after start (first request timed out once). The IME drops characters after a space: type `bash` Space `v.sh` separately.
- 15.11.2026: `pkg install mpv` on a Termux with older libs gives "CANNOT LINK EXECUTABLE ... libavcodec.so.63 not found": `pkg upgrade -y` repairs it (about 3 minutes, Wi-Fi). Check `mpv --version` after installing, and fall back to play-audio when mpv exits within 1.5 s. raw.githubusercontent.com caches a file about 5 minutes (a query string does not help): after pushing voiced.py wait until `curl .../voiced.py | wc -c` shows the new size before `phonesay update`, or the phone gets the old file again (same byte count in the answer is the sign).
